Virtual Sketching / ONNX Runtime Web

Raster image to vector strokes

The model runs one recurrent step at a time in the browser. JavaScript owns the crop, raster feedback, cursor, and stroke-rendering loop. Completed strokes are also kept as vector geometry for SVG export.

Loading ONNX model…

After a run, adjust the distance to join nearby path ends. Midpoint mode moves both ends to their shared midpoint; uncheck it to add a short connecting line instead. 0 keeps exact joining. Distance is in image pixels; larger values can connect separate details.

Run the vectorizer to preview joining.

Redraw samples each joined path and fits cubic Bézier curves. Lower tolerance preserves more detail; higher tolerance smooths more aggressively.

Higher tolerance removes more short paths whose sampled centerlines are already covered by aligned strokes from another contour. The original records are preserved while the preview is recomputed.

Preview paths use distinct colors to make joined geometry easier to follow; downloaded SVG paths remain black.

Integration notes

Line drawing uses the clean-line checkpoint and multi-round tracing. Rough sketch uses its own RGB checkpoint with 10 rounds of up to 128 steps and random cursor movements between rounds. Photo uses the separate RGB face checkpoint and one fixed-length pass (100 steps by default). Photo mode is portrait-focused, not a general scene vectorizer. Models load locally on demand; uploaded images stay in your browser and are never sent to a server.
